## 🚀 一键部署（推荐）

### 方案 A：Render（免费，5分钟上线）

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

1. 点击上方按钮
2. 登录 GitHub 账号
3. 点击 "Create Web Service"
4. 等待 2-3 分钟，获得专属链接

### 方案 B：本地运行

```bash
# 克隆项目
git clone https://github.com/yourusername/ai-trust-builder.git
cd ai-trust-builder

# 安装依赖
cd backend && npm install

# 启动服务
npm start

# 打开 http://localhost:3000
```
