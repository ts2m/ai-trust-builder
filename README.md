# 🤝 AI Trust Builder

> **深度互动画像 · 让 AI 真正懂你**

不是简单的标签堆砌，而是基于认知科学和人格心理学的深度测评。16道精心设计的题目，生成真正有洞察力的 AI 互动指南。

## ✨ 核心特色

- 🧠 **五大维度深度测评**：认知处理、沟通偏好、决策风格、信任建立、边界需求
- 🎯 **人格原画像**：不只是标签，而是完整的人格描述
- 📊 **维度分析报告**：每个维度都有详细解读
- 💡 **实用行动指南**：具体的 Dos 和 Don'ts
- 📝 **可导出的 USER.md**：直接给 AI 使用

## 📊 测评维度

### 1. 认知处理风格
- 整体 vs 细节
- 类比理解 vs 逻辑拆解
- 不同记忆模式

### 2. 沟通偏好
- 信息接收方式（结论/理据/选项/共创）
- 反馈接受方式（直接/引导/委婉）
- 情绪应对模式
- 回复长度偏好
- 核心价值排序

### 3. 决策风格
- 直觉型 vs 分析型 vs 实验型
- 关注风险 vs 关注机会
- 错误归因方式

### 4. 信任建立
- 什么让你感到被理解
- 愿意分享的话题领域
- 什么会立即摧毁信任

### 5. 边界与节奏
- 什么情况下会求助
- 什么时候觉得该结束对话
- 希望保持的关系距离

## 🚀 快速开始

### 本地运行

```bash
cd ai-trust-builder/backend
npm install
npm start

# 打开 http://localhost:3000
```

### 部署到 Render

1. Fork 这个仓库
2. 在 Render 上创建 Web Service
3. 连接你的仓库
4. 自动部署完成

## 🛠️ 技术栈

- **前端**：原生 HTML5 + CSS3 + JavaScript
- **后端**：Node.js + Express
- **数据**：SQLite3

## 📱 问卷流程

1. **输入ID** → 开始测评
2. **5个维度** → 逐个回答
3. **16道题目** → 单选+多选
4. **生成报告** → 人格画像 + 维度分析
5. **导出文件** → USER.md 供 AI 使用

## 💡 使用建议

将生成的 USER.md 提供给 AI 的方式：

**方式一**：将文件内容粘贴到对话开头
```
请根据以下 USER.md 了解我的互动偏好：
[粘贴内容]
```

**方式二**：如果 AI 支持文件上传，直接上传 USER.md

**方式三**：将关键信息作为 system prompt

## 📝 报告示例

```markdown
# USER.md - 张三 的 AI 互动指南

## 🎭 人格画像

**效率专家**

你追求结果，讨厌绕弯子。对你而言，时间就是一切，
最好的帮助是快速、准确、 actionable 的建议。

### 核心特质
- 结论优先
- 直接纠偏
- 极简型
- 急救模式

## 💬 沟通指南

### 应该这样做
- **结论先行**：先说结论，再问"需要详细解释吗？"
- **直接纠偏**：发现错误时说"这里有个问题：..."
- **效率模式**：用户烦躁时加速推进

### 千万不要
- ❌ **铺垫太长**：结论藏在大段文字后面
- ❌ **暗示纠错**：绕弯子让用户猜哪里错了
```
